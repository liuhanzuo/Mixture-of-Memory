Mixture of Memory · 混合记忆系统
为局部注意力大模型补偿长程上下文能力　|　刘涵祚
Mixture-of-Memory: Hierarchical Memory restores long-range context for local-attention LLMs at O(n·w) cost
① 研究动机
  • 全注意力 O(n²) 维持长上下文，但超长序列代价极高
  • 滑动窗口注意力 SWA 降到 O(n·w)，却丢失窗口外长程信息
  • 目标：SWA + 记忆 ≈ 全注意力性能
全注意力 O(n²) vs SWA O(n·w)
② 核心思想 · 三级记忆
  • 三级层次化记忆按时间尺度分层，类比人类记忆，固定 KV 预算压缩任意长上下文
  • L1 关联矩阵（每 token·在线）：衰减 key→value 矩阵，门控融合进隐藏态
  • L2 事件 Slot（每 chunk 边界）：128 slot，delta-rule 写残差 + 归一化读出
  • L3 语义摘要（每段）：从 L2 抽象的长期画像，支持冲突修订
  • 🔒 冻结骨干，仅训练记忆适配器（即插即用）
③ 算法主流程 — 长序列经三级记忆压缩并注入冻结骨干
④ 方法细节
  • 写入：delta-rule 写残差 + 容量归一化
  • 路由：query→slot top-k(=16)，loss-free 均衡
  • 读出：可训练 cross-attn + null-sink 去噪
  • 训练：8B 骨干冻结，chunk 渐进 128→1024

⑤ 实验结果 · BABILong qa5
MoM (ours) Llama-3-8B-Instruct
固定 KV 预算下，MoM 在 16k–32k 仍保持 46/41，而 vanilla Llama-3-8B-Instruct 超出训练长度即塌至 1/0（8k 训练窗口）。
⑥ 关键发现
  • chunk size 是最大杠杆（qa1@0k：89 vs 55）
  • delta-rule 写入 > 直接覆盖（当前最佳臂）
  • 读路径须可训练 + null-sink，否则连 0k 也塌
  • L3 语义重建权重过大反而损害检索（语义 ↔ 定位权衡）
⑦ 结论 & 未来工作
  • 三级记忆让 SWA 骨干在固定 KV 预算下，长程任务接近全注意力，效率 O(n·w)
  • 未来①：用加了 memory 的模型自蒸馏原模型
  • 未来②：训练引入 cross-chunk SWA 目标
  • 未来③：强化 L3 语义层应对全局总结任务
