# CoMem anonymous paper artifacts

This directory contains the review manuscript and figure sources. CoMem writes
intermediate residual states for context chunks, retrieves a bounded set per
query, and resumes upper transformer layers. The paper reports matched raw-text
replay controls, repeated-query serving measurements, and Write-context
ablations. Model weights and benchmark text are not redistributed.

Figure 1 was prepared through an AutoFigure-Edit import/reconstruction workflow
and manually rebuilt as an editable SVG. All labels and scientific claims were
checked by the authors.
