\section{Conclusion}
\label{sec:conclusion}

Post-pruning recovery is not one-dimensional. In the observed OLMo-2 prefix
recipe, held-out likelihood improves substantially while answer-letter MMLU and
closed-book QA remain far below the intact model. An intact same-corpus control,
complete-option scoring, same-shape operating points, and a ShortGPT
construction comparison show that corpus drift, answer interface,
initialization/adaptation, and exact structure each affect the interpretation.
Perplexity remains an
essential measure of distributional fit, but it is not a sufficient certificate
that a target behavior has returned after structural intervention. Compression
studies should report likelihood, target capability, scoring interface, exact
structure, and recovery compute as separate axes.
