## M. Protocol, stated once and applied everywhere

- **`chat_template = False` for every number in this paper.** The models evaluated are **base
  LMs with no SFT and no RLHF**, so applying a chat template would be an unfair and
  non-comparable measurement. Asserted with `is False` in gate G3; **`is not True` is banned**
  because it passes on `None`.
- `add_bos = 0`, `desc_style = none`, `MAXLEN = 2048` (MMLU-Pro), fp32 master weights with
  bf16-autocast forward, `batch_size = 48`.
- Scoring is **likelihood-based throughout**. `scripts/eval_olmo2_mc_letter_content.py:500-622`
  scores the candidate continuations `" A"`, `" B"`, ... by summed token log-probability and
  takes the argmax; the per-item records carry the full log-prob vector, e.g.
  `{"A": -3.322937, "B": -7.510437, ...}`. **There is no sampling, no decoding, no regex over
  generated text.** So "the model emits A on 90% of items" means the letter `A` wins the
  log-prob argmax on 90% of items. **The collapse is in the argmax of a likelihood**, which is
  why the fix has to change the *null*, not the interface.
- Statistics: paired bootstrap `n_boot = 10000`, `seed = 7`, two-sided **mid-p**
  `two_sided_boot_p()`; exact McNemar wherever the null is a deterministic per-item 0/1
  decision; permutation `n_perm = 10000` for v2.
- Integrity asserts per cell: shard index set `== {0..7}`, `n == expected`, 0 duplicate ids,
  `n_nan == 0`, `n_trunc == 0`. The merge **RAISES** on a partial shard set (this is what caught
  the Llama-2 OOM at 3/8 instead of silently reporting it).
